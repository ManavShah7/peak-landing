# Peak — landing page

Static landing page for Peak, an iOS fitness companion.
No build step: `index.html` plus `img/`. Open the file, or serve the folder.

Screenshots in `img/` are frames pulled from the September capture reel.

## Waitlist
The form posts to Supabase. It stays in mailto-fallback mode until you paste the
anon key into `SUPABASE_ANON_KEY` at the bottom of `index.html`.
